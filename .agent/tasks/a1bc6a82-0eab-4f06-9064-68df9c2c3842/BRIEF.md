# Task brief

Canary 02 · Фильтрация синтетического каталога

В синтетическом inventory API добавить GET /api/items?min_quantity=N: неотрицательное целое N отфильтровывает товары с quantity меньше N; без параметра вернуть прежний полный каталог. Неверное значение, отрицательное, дробное или повторный параметр дают HTTP 400 JSON с понятной ошибкой. Не менять данные и UI. Добавить автоматические проверки чистой функции и HTTP поведения. UAT не требуется. Полный маршрут с архитектором, оппонентом и независимым согласованием владельца.
