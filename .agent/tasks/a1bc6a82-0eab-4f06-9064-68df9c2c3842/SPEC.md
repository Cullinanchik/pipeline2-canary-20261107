# Canary 02 · Фильтрация синтетического каталога

Цель: фильтр минимального остатка в синтетическом inventory API.

- AC1: GET /api/items без min_quantity возвращает прежний полный каталог и HTTP 200 JSON.
- AC2: Неотрицательное целое min_quantity=N оставляет только товары с quantity >= N; граница включена, N=0 возвращает все, порог выше максимума возвращает пустой массив.
- AC3: Неверное, пустое, отрицательное, дробное значение и повтор min_quantity дают HTTP 400 JSON с понятной ошибкой.
- AC4: Исходные данные, свежесть возвращаемых значений, UI и остальные маршруты сохраняют прежнее поведение.
- AC5: Добавлены автоматические проверки чистой функции и HTTP поведения для AC1–AC4.

Область: api.py, app.py, tests/test_api.py. Без изменения данных, UI, зависимостей и миграций. UAT не требуется по brief. Детали допустимой записи целого и верхней границы уточняет планировщик; нельзя допускать округление или игнорировать повторы.
