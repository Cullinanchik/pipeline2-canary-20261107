# Task brief

Canary 03 · Резервирование синтетических товаров

Добавить к синтетическому inventory сервис резервирования остатков с SQLite и POST /api/reservations, GET /api/items. Каждая резервация содержит item_id, положительное quantity и непустой idempotency_key. Повтор того же ключа с теми же данными возвращает исходную резервацию; другие данные с тем же ключом дают 409. Конкурентные запросы не могут сделать остаток отрицательным. Использовать транзакции, обеспечить восстановление после рестарта и тесты гонки/rollback/идемпотентности. Начальные товары прежние. Без внешних сервисов и настоящих данных, без UI; UAT не требуется. Архитектор отвечает за полный контракт и миграцию. План сначала проходит спор моделей и согласование владельца. Это согласованный изолированный E2E; не менять production и не выполнять чужие роли.
