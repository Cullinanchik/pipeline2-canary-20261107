# Canary 03 · Решение по дизайну резервирования

Визуальный дизайн не требуется: UI вне области задачи, UAT не требуется согласно BRIEF. Решение зафиксировано в design.json.

Архитектурное проектирование требуется в полном маршруте: planner определяет HTTP-контракт, схему SQLite, миграцию, атомарные транзакции, идемпотентность и восстановление в соответствии с AC1–AC6 из SPEC.md. Это решение Triage, а не готовая архитектура и не одобрение плана.
