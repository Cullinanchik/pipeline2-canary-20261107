# Canary 01 · Решение по дизайну

Решение: дизайн не требуется (`design.json`: `required: false`).

- Экран и код не меняются: `app.py` уже выводит `Status: <badge>` и кнопку `<button>` из `labels.json` (SPEC F6).
- Повторно используются `app.py` и `labels.json` в том виде, в каком они в базе интеграции B (сейчас `fdbf1e4` = main):
  меняется только текст статуса `Draft` → `Ready`; подпись кнопки `Reload items` берётся из B без изменений (SPEC D2, D6).
- Новых элементов, состояний, стилей и текстов, кроме слова статуса, нет, поэтому макет и визуальная проверка не нужны.
