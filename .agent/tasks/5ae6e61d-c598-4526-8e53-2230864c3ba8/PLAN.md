# Canary 01 · План замены статуса

Быстрый маршрут: mechanical, low risk, high confidence.

1. Builder заменяет единственное вхождение Draft на Ready в labels.json (AC1).
2. Сравнивает результат с базовым файлом: точная замена и отсутствие прочих изменений (AC2).
3. Коммитит результат и запускает `scripts/agent-check --phase quick`; оформляет handoff.
4. Контроллер выполняет полную проверку на этапе Verify после завершения сессии.

Команда сравнения: `git diff 2561257509ca69974ef162cff07d264a98b5553b -- labels.json`.
На Triage исходники не изменяются, проверки приложения не запускаются.
