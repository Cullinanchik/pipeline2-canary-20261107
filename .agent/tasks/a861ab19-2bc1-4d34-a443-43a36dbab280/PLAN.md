# Canary 08 · Параллельная задача A

Быстрый механический маршрут: builder → reviewer.

1. Builder заменяет единственное pending на completed в notes/parallel-a.txt (AC1).
2. Проверяет точный diff и отсутствие других изменений приложения (AC2), коммитит изменение до финальной быстрой проверки scripts/agent-check --phase quick.
3. Reviewer читает сохранённые request.checks; устаревшие результаты возвращаются в Verify. Полный набор тестов запускает только контроллер после handoff и завершения сессии.
4. UAT и дизайн не нужны (AC3).
